KILO

Modern Android music player with native crossfade, Spotify browsing, and YouTube Music hybrid playback.

Latest Release View Source Spotify API YouTube Music Android Auto GPLv3

Features

🔀

Native Crossfade Engine

C++/NDK mixer with Oboe — equal-power curves, Automix EQ sweep (HPF 20→350Hz), soft clipping, lock-free ring buffers. 0–12s configurable.

🎵

Native Spotify Browsing

Full catalog inside the app — New Releases, Featured Playlists, Categories, Library. No browser needed. sp_dc cookie auth with auto token refresh.

🔄

Hybrid Source Modes

Choose: Both (Spotify metadata + YT Music audio), Spotify Only, or YouTube Music Only. Persisted globally, filtered at provider registry.

🌍

Lyrics Translation

Any language → English via MyMemory API. Auto-detection, local caching, toggle in settings.

🎚️

Equalizer & DSP

10-band parametric EQ, bass boost, virtualizer, loudness enhancer. Native mixer integration planned.

🚗

Android Auto

Media3 session integration — browse, play, queue, control from car display.
