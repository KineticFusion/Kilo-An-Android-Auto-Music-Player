# KILO 1.5.0

## What's new

- Added synchronized lyrics in the player.
- Added live radio browsing and playback.
- Added offline downloads, download progress, faster parallel transfers where supported, and scanning for audio already in the selected folder.
- Updated the redesigned player and library screens.
- Improved Android Auto browsing, track loading, queue restoration, and playback startup.
- Improved stream recovery, seeking, and track transitions.

## Install

Download `Kilo-1.5.0.apk` from the release assets and install it on your Android device. Android may ask you to allow installs from the app you use to open the APK.
