# Kilo 2.1.0 — Profile & Personalization Hotfix

This hotfix makes listener profiles independent while allowing them to share the same YouTube Music account.

## What's new

- Create multiple listener profiles under one signed-in account.
- Keep each profile's moods, genres, followed artists, discovery level, audio preference, and Android Auto preference separate.
- Switch profiles and open a clean personalization setup for a new listener.
- Reset the active profile's personalization and start choosing preferences again.
- Reset all Kilo app data from Settings and return to the first-run setup wizard.
- Existing single-profile personalization is migrated into the active profile.
- Select one mood and one genre per profile; Home's similar and unplayed-discovery shelves now respond to those selections.
- Browse all 25 Android Auto layouts with previews, and set a custom player accent using a HEX color value.
- Save and load personalization presets as XML through the Android file picker, using any folder you choose.
- Follow artists directly from search, choose from an expanded worldwide and regional setup list, and like songs from their rows or options menu.
